## 环境选择

原 `platformio.ini` 默认 `can_b_replay`；原 `compile.sh` 默认 `can`，README 推荐的正式业务入口为 `main`。三者不一致，导入时保留原状。构建时必须显式指定环境。

```sh
cd firmware
pio run -e main
# 独立网关：pio run -e can_gateway
# 抓包分析：pio run -e analyzer
```

这些命令用于说明入口，不表示已编译通过。P 系列正式发布面向 ESP32-P4 三 CAN，此工程配置为 ESP32-S3 双 CAN，两者不能直接视为相同固件。
